<details>
  <summary><strong>What does “Gutter” mean in Microsoft Word?</strong></summary>
  <p>The gutter is extra margin space added to the side or top of a page to allow for binding. It prevents text from disappearing into the spine when a document is bound.</p>
</details>

<details>
  <summary><strong>How can I control the text margins inside table cells?</strong></summary>
  <p>You can control text margins by adjusting <em>cell margins</em>:</p>
  <ul>
    <li>Select the cell(s) → Table Layout → Cell Margins → adjust top/left/right/bottom.</li>
    <li>Or right‑click → Table Properties → Cell → Options → set margins.</li>
    <li>You can also use paragraph indents within a cell for fine adjustment.</li>
  </ul>
</details>

<details>
  <summary><strong>Does Word have a Column Break feature?</strong></summary>
  <p>Yes. Insert → Break → Column Break forces text to begin at the top of the next column in a multi‑column layout.</p>
</details>

<details>
  <summary><strong>How do I make a 2‑column table span the width of a column and keep both columns equal?</strong></summary>
  <ul>
    <li>Use AutoFit → AutoFit to Window to fit the table to the current column width.</li>
    <li>Select the table → Table Layout → Distribute Columns to equalize column widths.</li>
    <li>Ensure “Preferred width” is unchecked in Table Properties (unless you want fixed widths).</li>
  </ul>
</details>

<details>
  <summary><strong>How do I control the gap between text columns?</strong></summary>
  <p>Go to Layout → Columns → More Columns → adjust the <strong>Spacing</strong> value. You may also enable “Line between” for a visible separator.</p>
</details>

<details>
  <summary><strong>How do I control the left and right margins of text in a table column?</strong></summary>
  <ul>
    <li>Use Table Layout → Cell Margins.</li>
    <li>Or Table Properties → Cell → Options → set left/right margins.</li>
    <li>Paragraph indents inside the cell can also adjust text positioning.</li>
  </ul>
</details>

<details>
  <summary><strong>How can I add custom spacing between an image and a table?</strong></summary>
  <ul>
    <li><strong>Add paragraph spacing after the image</strong> (best method).</li>
    <li>Or add paragraph spacing before the table.</li>
    <li>If the image is wrapped, you can also adjust its position or wrapping settings.</li>
  </ul>
</details>

<details>
  <summary><strong>Can I make an image span the width of its column?</strong></summary>
  <p>Yes. Make the image “Inline with Text” and set its width to the column width, or use Picture Format → Size → set width to 100% relative to column.</p>
</details>

<details>
  <summary><strong>Can Microsoft Word have 4 columns?</strong></summary>
  <p>Yes. Go to Layout → Columns → More Columns → set Number of columns to 4. You can adjust width, spacing, and choose equal widths.</p>
</details>
